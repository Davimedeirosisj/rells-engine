# 🚀 RELLS ENGINE - Superpoderes do ECC

**Objetivo:** Transformar este projeto de video-processing em uma aplicação profissional com recursos modernos!

---

## 📋 **Contexto do Projeto**

- **Tecnologia:** React + Node.js + Express + FFmpeg
- **Função:** Processamento automático de cortes de vídeo vertical (1080x1920)
- **Entrada:** Vídeo MP4 + SRT + cortes.json
- **Saída:** ZIP com MP4s prontos para Instagram/TikTok
